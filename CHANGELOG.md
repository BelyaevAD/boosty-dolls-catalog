# История изменений

## Не выпущено

- исправлен рекурсивный обработчик сброса фильтров, из-за которого каталог зависал и сохранял параметры в URL.
- каталог ограничен страницами с преимущественно русскоязычным публичным содержимым; имя автора и название канала больше не подтверждают язык;
- язык оценивается по описанию, последним публикациям, уровням подписки и платным материалам;
- семь широких разделов заменены одиннадцатью исследовательскими категориями;
- discovery расширен до 75 русскоязычных поисковых формулировок;
- за один проход можно опубликовать не более 200 новых профилей, а прошедшие квалификацию сверх лимита остаются в очереди.
- полный русскоязычный проход расширил очередь до 3 988 кандидатов и каталог до 138 проверенных каналов: добавлено 53, удалено 12.

## 1.0.0 — 2026-08-06

- создан самостоятельный Boosty Dolls Каталог на основе проверенной архитектуры Boosty IT Catalog;
- добавлена схема данных 2 с независимыми ценами подписки и разовых материалов;
- реализованы быстрые переключатели двух моделей оплаты, фильтр «оба формата» и независимые ценовые сортировки;
- добавлены семь кукольных направлений и многозначная классификация;
- реализован массовый discovery по публичному каталогу и 49 узким запросам Boosty;
- сохранены общий scheduler, retry/cooldown, очередь кандидатов и ручные исключения;
- карточки, таблица, модальное окно и страницы авторов показывают модели оплаты отдельно;
- добавлены sitemap, RSS, robots.txt, JSON-LD, CSP и адаптивный интерфейс;
- удалён сторонний GitHub iframe: сайт не загружает сторонний JavaScript, изображения или трекеры;
- настроены CI, еженедельное обновление и GitHub Pages;
- добавлены исследовательский отчёт и Agent OS спецификация.
