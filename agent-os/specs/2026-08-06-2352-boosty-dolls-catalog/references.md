# Референсы

## Boosty IT Catalog

- Репозиторий: https://github.com/BelyaevAD/boosty-it-catalog
- Используемые паттерны: статическая генерация, публичный и сырой наборы данных, карточки/таблица, URL-фильтры, детальные страницы, CSP, RSS/sitemap, GitHub Pages, единый scheduler для Boosty.
- Изменяемые части: критерий платной подписки, IT-таксономия, ценовая модель, тексты, визуальные акценты и discovery-запросы.

## Исследование проекта

- Локальный отчёт: RESEARCH_REPORT.md
- Наблюдаемая выборка: 190 высокоуверенных профилей.
- Плановый обнаруживаемый пул: 240–300 профилей.
- Ключевой вывод: разовые материалы распространены сильнее подписки, поэтому оба формата являются базовыми.
