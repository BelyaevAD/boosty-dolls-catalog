# План реализации Boosty Dolls Catalog

## Цель

Создать полностью рабочий статический каталог русскоязычных и двуязычных авторов Boosty в кукольной тематике, сохранив сильные стороны Boosty IT Catalog и адаптировав модель данных и интерфейс к двум равноправным способам монетизации: ежемесячной подписке и разовой покупке материалов.

## Этапы

1. Сохранить спецификацию и решения до начала реализации.
2. Перенести проверенную статическую архитектуру референса без пользовательских данных.
3. Заменить IT-таксономию на кукольную и расширить схему монетизации.
4. Реализовать воспроизводимый сбор, квалификацию, санитарную обработку и обновление данных.
5. Выполнить массовый сбор и сформировать публичный каталог.
6. Адаптировать карточки, таблицу, детали, отдельные страницы, SEO, RSS и sitemap.
7. Добавить тесты, проверки данных, сборки и GitHub Actions.
8. Провести функциональную, визуальную, адаптивную и security-проверку.
9. Опубликовать репозиторий и проверить GitHub Pages, если доступна существующая Git-аутентификация.

## Критерии готовности

- В каталоге присутствуют реальные квалифицированные профили Boosty.
- В интерфейсе отчётливо различаются «Подписка» и «Разовая покупка», доступен фильтр «Оба формата».
- Цена подписки и цена разового материала никогда не смешиваются в одном поле.
- Поддерживаются семь верхнеуровневых категорий и многозначные теги.
- Работают поиск, фильтры, сортировка, карточки, таблица, модальное окно и отдельные страницы.
- Генерируются robots.txt, sitemap.xml, RSS, JSON-LD и социальные метаданные.
- Публичные тексты не содержат контактных данных, сырых внешних ссылок и служебных доказательств.
- Все запросы Boosty используют один планировщик с глобальным cooldown.
- npm run check, git diff --check и визуальная проверка проходят.
- GitHub Actions публикует dist в Pages без секретов в репозитории.

## Откат

До первого коммита исходное состояние состоит только из RESEARCH_REPORT.md. При проблемах изменения можно удалить отдельным новым коммитом; опасные Git-команды и перезапись истории не используются.
