# План русскоязычного расширения каталога

## Цель

Перевести Boosty Dolls Каталог на строго русскоязычный допуск, расширить охват ранее найденных кукольных профилей и опубликовать не более 200 новых авторов за один запуск.

## Этапы

1. Сохранить спецификацию и измеримые правила до реализации.
2. Определять язык по совокупности доступного публичного контента: описанию, заголовкам и тизерам последних публикаций, платным материалам и уровням.
3. Перевести исследовательские подтипы кукол в полную пользовательскую таксономию и расширить русские поисковые запросы.
4. Добавить жёсткий лимит 200 новых публикаций за запуск с явным учётом отложенных квалифицированных кандидатов.
5. Выполнить полный повторный discovery и recheck всех найденных кандидатов через штатный updater.
6. Проверить все добавления, необычные классификации, языковой допуск, приватность и ошибки загрузки.
7. Обновить интерфейс, документацию, тесты и исследовательский отчёт.
8. Опубликовать изменения, дождаться CI/Pages и проверить production.

## Критерии готовности

- язык каждого опубликованного профиля подтверждён совокупностью содержательных сигналов;
- случайная кириллица в имени или названии не считается достаточным доказательством;
- русскоязычный discovery исчерпан в рамках доступных штатных источников;
- один запуск добавляет от 0 до 200 новых карточек, никогда больше;
- квалифицированные профили сверх лимита не помечаются нерелевантными;
- категории отражают основные исследовательские сегменты, а не скрывают их внутри общего раздела;
- `errors` пуст, `totalOutstandingFetchErrors` равен нулю;
- `npm run check`, `git diff --check`, security-проверка, браузерный smoke-test и GitHub Pages проходят.

## Откат

Изменения выпускаются отдельным коммитом поверх `f019d2c`. Откат выполняется новым revert-коммитом без перезаписи истории; исходные кандидаты и ручные исключения сохраняются.
