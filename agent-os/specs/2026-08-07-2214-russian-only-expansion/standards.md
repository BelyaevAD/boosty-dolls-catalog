# Стандарты русскоязычного расширения

## Данные и квалификация

- Канонический lowercase slug является ключом дедупликации.
- Preflight использует доступное описание как ранний сигнал, но окончательный язык проверяется по описанию, заголовкам и публичным тизерам постов, платным материалам и уровням.
- Имя и название не могут самостоятельно перевести профиль в русскоязычный статус.
- Релевантность, наличие публикаций, монетизация, adult/blocked и ручные исключения остаются обязательными независимыми воротами.
- Ограничение публикации не должно превращать квалифицированного автора в `unqualified`.

## Сеть и устойчивость

- Все Boosty-запросы проходят через один scheduler и общий cooldown.
- Разрешены только фиксированные HTTPS-хосты; slug проходит allowlist.
- 404/410 считаются терминальными, 429/5xx/timeout — временными.
- Релиз блокируется при любой ошибке обновления опубликованного профиля или ненулевом общем числе fetch-errors.

## Приватность и клиентская безопасность

- Публичные описания проходят `sanitizePublicSummary` и `findPublicContactKinds`.
- Не публикуются e-mail, телефоны, платёжные данные, messenger handles, URL и прямые инструкции связаться.
- Динамический HTML не строится из недоверенных строк; используются безопасные DOM API и экранирование генератора.
- Не добавляются cookies, browser storage, сторонний JavaScript, аватары или трекеры.

## CI и supply chain

- Используется `npm ci --ignore-scripts`, lockfile и закреплённые SHA GitHub Actions.
- Workflow сохраняют минимальные permissions.
- Перед публикацией выполняются тесты, data/build validation, `npm audit` и проверка секретов.
