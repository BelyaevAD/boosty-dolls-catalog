# Русскоязычное расширение — решения

## Объём

Новый релиз существующего каталога: правила допуска, discovery, классификация, данные, документация, UI-счётчики и публикация.

## Решения

- Каталог предназначен только для русскоязычной аудитории.
- Язык определяется по совокупности описания, заголовков и публичных тизеров последних публикаций, платных материалов и уровней подписки.
- Имя автора, название канала, slug и бренды не являются самостоятельным языковым доказательством и имеют только слабый вспомогательный вес.
- Профиль проходит, когда содержательный публичный корпус преимущественно русский либо несколько независимых частей контента дают устойчивое русское свидетельство.
- Все поисковые формулировки пишутся по-русски; латинские бренды и аббревиатуры допустимы только внутри русского запроса.
- За один запуск публикуется не более 200 новых авторов. Лимит не ограничивает число проверенных кандидатов.
- Квалифицированные кандидаты сверх лимита остаются ожидающими следующего выпуска.
- Семь MVP-разделов заменяются полной исследовательской таксономией крупных кукольных сегментов.

## Контекст

- В исходном исследовании найдено 190 высокоуверенных профилей и оценён полный пул 240–300.
- До расширения каталог содержал 97 авторов и 878 известных кандидатов.
- Полный проход проверил 3 887 адресов; после ручной курации опубликовано 138 каналов, в очереди сохранено 3 988 кандидатов.
- Референс: штатные `scripts/update-data.mjs`, `scripts/lib/catalog.mjs` и `RESEARCH_REPORT.md`.
- Визуальные изменения ограничены названиями и количеством тематических фильтров; две модели оплаты сохраняются без изменений.

## Риски

- Короткие профили могут давать мало текста; для них требуется несколько независимых русских сигналов, иначе публикация откладывается.
- Публичный поиск Boosty неполон; результат является исчерпывающим только для доступных источников и текущей даты.
- Автоматическая классификация требует ручного просмотра новых и многотематических профилей.
