# Стандарты углублённого внутреннего поиска

## Данные и квалификация

- Canonical lowercase slug остаётся ключом дедупликации.
- Язык определяется содержательным корпусом: описанием, постами, публичными тизерами, тарифами и платными материалами.
- Тематическая оценка различает число совпавших терминов и число независимых релевантных постов.
- Новый мягкий путь релевантности не отменяет русский язык, монетизацию, наличие постов, adult/blocked и ручные исключения.
- Пограничные случаи сохраняют измеримые причины и не теряются из очереди.

## Сеть и API

- Все запросы Boosty проходят через единый `fetchBoostyJson` scheduler и общий cooldown.
- Используются только фиксированные HTTPS-хосты; slug и параметры имеют allowlist/range validation.
- Пагинация ограничена по числу страниц и публикаций.
- 404/410 терминальны; 429/5xx/timeout временны и не превращаются в отсутствие канала.
- Токен GitHub отправляется только `api.github.com` и не логируется.

## Приватность и логирование

- Публичные строки проходят санитарную обработку контактов и URL.
- Логи содержат slug и тип ошибки, но не найденное контактное значение, токены или сырые ответы.
- Не сохраняются cookies, browser storage, authorization headers или внешние профили.

## CI и supply chain

- Единственный weekly workflow использует минимальные permissions, pinned SHA actions и `npm ci --ignore-scripts`.
- Коммит автоматизации ограничен деревом `data/` и создаётся только после полной валидации.
- Сохраняется жёсткий предел 200 новых публикаций за запуск.
- Перед релизом выполняются `npm run check`, `git diff --check`, `npm audit` и secret/privacy scan.
