# План углублённого внутреннего поиска

## Цель

Увеличить охват русскоязычного каталога за счёт более точной оценки публикаций и дополнительных внутренних запросов Boosty, не используя Telegram, VK, Дзен, YouTube, Livemaster или внешние страницы авторов.

## Этапы

1. Сохранить спецификацию, ограничения источников и критерии готовности.
2. Расширить таксономию подтверждёнными сегментами народных и театральных кукол.
3. Добавить узкие запросы только во внутренний поиск Boosty и site-restricted поиск страниц Boosty.
4. Заменить подсчёт разнообразия ключевых слов оценкой устойчивости темы по нескольким публикациям.
5. Читать несколько страниц публичной истории постов, а не только первые двадцать записей.
6. Убрать ранний тематический отказ до чтения публикаций для кандидатов с русским свидетельством из Boosty или Common Crawl.
7. Адаптировать существующий еженедельный GitHub Actions workflow к новому глубокому проходу без создания дублирующей автоматизации.
8. Повторно проверить пограничные и ранее остановленные профили, опубликовав не более 200 новых каналов.
9. Проверить данные, категории, приватность, CI, Pages и публичные счётчики.

## Критерии готовности

- окончательная релевантность учитывает число тематических публикаций, а не только число разных ключевых фраз;
- русскоязычный кандидат не отклоняется до чтения постов только из-за нейтрального описания;
- анализируется до 60 публичных публикаций с ограниченным числом запросов и общим scheduler;
- внешние социальные и авторские площадки не используются для discovery;
- новые категории подтверждены результатами внутреннего поиска Boosty;
- один запуск публикует максимум 200 новых каналов;
- существующий weekly workflow запускается по расписанию, имеет минимальные permissions и выполняет валидацию перед коммитом;
- `errors` пуст, `totalOutstandingFetchErrors` равен нулю;
- тесты, data/build validation, privacy checks, CI и GitHub Pages проходят.

## Откат

Изменения выпускаются отдельным коммитом. Откат выполняется revert-коммитом; исходная очередь кандидатов и ручные исключения сохраняются.
