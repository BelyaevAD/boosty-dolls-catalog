# Углублённый внутренний поиск — решения

## Объём

Изменение discovery, preflight, релевантности, таксономии, еженедельной автоматизации и повторного выпуска данных существующего каталога.

## Решения

- Разрешённые источники нового discovery: публичный API и каталог Boosty, внутренний поиск постов Boosty, русские страницы Boosty через site-restricted поиск и Common Crawl с `languages:rus`.
- Не добавляются Telegram, VK, Дзен, YouTube, Livemaster и внешние страницы авторов.
- Имя автора и название канала не считаются языковым доказательством.
- Кандидат с русским discovery-сигналом получает ограниченный глубокий просмотр публикаций, даже если профильное описание нейтрально.
- Один тематический термин может быть достаточен только при повторении в нескольких независимых публикациях либо при подтверждённом попадании внутреннего поиска Boosty и профильном тематическом сигнале.
- Публикация по-прежнему требует русского контента, постов, монетизации, отсутствия adult/blocked и прохождения тематического порога.
- Добавляются категории «Народные, обрядовые и обережные куклы» и «Театральные куклы и марионетки».
- Техники из капрона, фарфор, бренды коллекционных кукол и 3D-печать расширяют запросы и существующие категории, но не создают лишних малых разделов.
- Существующий Friday workflow сохраняется как единственный weekly updater.

## Контекст

- В очереди 3 988 кандидатов; 2 017 Common Crawl-профилей ранее остановлены до чтения постов.
- Среди полностью проверенных отказов есть 179 русскоязычных профилей с одним тематическим сигналом.
- Контрольная выборка 30 таких профилей дала 12 кандидатов для ручной проверки после перехода к оценке повторяемости темы.
- Внутренний поиск Boosty подтвердил отдельные сегменты народных/обрядовых и театральных кукол.
- Визуальные изменения ограничены новыми фильтрами и пересчитанными данными.

## Риски

- Глубокий проход увеличит число Boosty API-запросов; общий scheduler, cooldown, пагинация и недельный бюджет обязательны.
- Театральные запросы могут находить общие театры и постановки; окончательный допуск должен требовать устойчивую кукольную специализацию.
- Более мягкий тематический порог увеличивает ложноположительные результаты; новые и необычные категории требуют ручной проверки.
