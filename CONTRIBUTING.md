# Как помочь проекту

Спасибо за участие в развитии Boosty Dolls Каталога.

## Предложить или исправить автора

Для изменений данных предпочтительны шаблоны GitHub Issues:

- **Предложить автора** — новая страница Boosty;
- **Исправить данные** — неверная тема, формат оплаты, устаревший или удалённый профиль.

Не добавляйте личные контакты, закрытые материалы, cookies, токены или другую непубличную информацию.

## Изменить код

1. Создайте fork и отдельную ветку.
2. Выполните `npm ci`.
3. Внесите небольшое сфокусированное изменение.
4. Запустите `npm run check`.
5. Откройте pull request и опишите причину и результат.

Проект использует только Node.js и браузерные стандарты, без runtime-зависимостей. Пользовательские и внешние данные должны попадать в DOM через безопасные текстовые API; не используйте `innerHTML`, `eval` или inline-обработчики событий.

## Критерии автора

Автор может попасть в публичный каталог, если:

- публичные материалы профиля ведутся преимущественно на русском языке;
- тематика явно относится к куклам и кукольной миниатюре;
- существует платная подписка или отдельный платный материал;
- есть хотя бы одна публикация;
- публичная страница доступна и не заблокирована.

Основная тема остаётся первой в `category`, а дополнительные подходящие направления сохраняются
в массиве `topics`. Один автор может участвовать сразу в нескольких тематических фильтрах. Цены
  подписки и разовой покупки должны храниться в разных полях.

Язык оценивается по описанию, последним публикациям, уровням подписки и платным материалам. Имя автора и название канала не являются достаточным доказательством.
