# Boosty Dolls Каталог

Открытый каталог кукольных авторов на Boosty, чьи публичные материалы ведутся преимущественно на русском языке. Проект помогает отдельно сравнивать два распространённых формата монетизации:

- **подписка** — регулярный доступ к закрытым публикациям и сообществу;
- **разовая покупка** — отдельный PDF, выкройка, урок, курс или другой платный материал.

Каталог не связан с Boosty, не продаёт места и не получает комиссию.

## Возможности

- карточный и табличный режимы;
- быстрый выбор «Подписка» или «Разовая покупка»;
- отдельный фильтр авторов, использующих оба формата;
- независимые ценовые ограничения и сортировки для подписки и разовых материалов;
- тринадцать верхнеуровневых направлений и многозначные теги;
- поиск, активность, аудитория и рост между снимками;
- отдельная индексируемая страница каждого автора;
- sitemap.xml, RSS, robots.txt, JSON-LD и социальные метаданные;
- адаптивный интерфейс без стороннего JavaScript и трекеров;
- воспроизводимое автоматическое обновление публичных данных Boosty.

## Тематическая структура

1. Вязаные куклы и амигуруми.
2. Текстильные и интерьерные куклы.
3. BJD и шарнирные куклы.
4. Авторские и арт-куклы.
5. Реборн-куклы.
6. Кастом и OOAK.
7. Одежда и выкройки.
8. Аксессуары для кукол.
9. Миниатюры и кукольные дома.
10. Коллекционирование и кукольные медиа.
11. Ремонт, реставрация и история.
12. Народные, обрядовые и обережные куклы.
13. Театральные куклы и марионетки.

Blythe, Barbie, Monster High, Pullip, Dollfie, Fashion Royalty, чулочная техника, 3D-печать и масштабы 1:6/1:12 дополнительно представлены как фокус и поисковые признаки.

## Локальный запуск

Требуется Node.js 20 или новее.

```powershell
npm ci
npm run check
npx serve dist
```

Сайт будет собран в `dist/`. Для корректных canonical URL при сборке задайте:

```powershell
$env:SITE_URL = "https://example.github.io/boosty-dolls-catalog/"
$env:REPOSITORY_URL = "https://github.com/example/boosty-dolls-catalog"
npm run build
```

## Обновление данных

Обычный еженедельный запуск:

```powershell
npm run update:data
npm run check
```

Полный проход без общего лимита кандидатов:

```powershell
npm run update:data:full
npm run check
```

Все запросы к Boosty проходят через общий планировщик и cooldown. Переменная `BOOSTY_REQUEST_INTERVAL_MS` регулирует минимальный интервал. За один запуск публикуется не более 200 новых профилей; прошедшие проверку сверх лимита остаются в очереди с причиной `publication-limit`. HTTP 404/410 считаются терминальными, а 429/5xx/timeout остаются временными ошибками.

Перед выпуском обязательно проверяются:

- `data/latest-update.json`: `errors` пуст, `totalOutstandingFetchErrors` равен нулю;
- уникальность slug и Boosty URL;
- типы и диапазоны цен;
- соответствие модели оплаты фактическим уровням или платным постам;
- отсутствие контактных данных в публичных текстах;
- минимум 20 новых авторов и все необычно широкие классификации;
- `npm run check` и `git diff --check`.

## Данные

- `data/channels.json` — очищенный публичный каталог.
- `data/raw/boosty-candidates.json` — техническая очередь кандидатов и состояния проверки.
- `data/manual-exclusions.json` — осознанные ручные исключения.
- `data/latest-update.json` — отчёт последнего прохода.
- `data/history/` — компактные снимки для расчёта динамики.

Публичная схема версии 2 хранит цены раздельно:

- `minSubscriptionPriceRub`, `maxSubscriptionPriceRub`, `tiers`;
- `minOneOffPriceRub`, `maxOneOffPriceRub`, `oneOffItems`;
- `paymentTypes`: `subscription`, `one-off` или оба значения.

Разовый материал и тематическая устойчивость определяются по метаданным до 60 публичных публикаций. Это не гарантирует, что материал продолжает продаваться — условия нужно перепроверять на Boosty.

## Правила включения

Публикуется профиль, который:

- ведёт публичные материалы преимущественно на русском языке;
- имеет публикации и не заблокирован;
- не помечен как adult;
- явно относится к куклам либо содержит повторяющуюся кукольную тему в нескольких публикациях;
- имеет хотя бы один платный уровень подписки или разовый платный материал.

Смешанные рукодельные профили проходят только при подтверждённой кукольной специализации. Публичное число подписчиков показывается как размер аудитории и не трактуется как число платящих людей.

Язык определяется по совокупности доступного публичного контента: описанию, заголовкам и публичным тизерам до 60 публикаций, названиям уровней подписки и платных материалов. Имя автора, название канала, slug и бренды не могут сами по себе подтвердить русский язык.

## Безопасность и приватность

- нет cookies, аналитики и стороннего JS;
- аватары и платные изображения не копируются;
- внешние ссылки открываются только по действию пользователя;
- CSP запрещает сторонний код и встраивание сайта;
- slug и сетевые хосты проверяются по allowlist;
- e-mail, телефоны, платёжные реквизиты, мессенджеры, URL и прямые инструкции связаться удаляются из публичных описаний;
- токены, cookies, browser storage и авторизационные заголовки не используются и не сохраняются.

## Автоматизация и публикация

Workflow `.github/workflows/update-data.yml` запускается каждую пятницу в 17:17 по часовому поясу `Asia/Barnaul`, обновляет каталог, проверяет его и фиксирует только изменения в `data/`. Он обходит 75 из 95 внутренних запросов Boosty с недельной ротацией и до 250 кандидатов, включая до 100 ранее остановленных до чтения постов; новый авторский выпуск по-прежнему ограничен 200 карточками. Workflow `.github/workflows/pages.yml` собирает статический сайт и публикует `dist/` в GitHub Pages с минимальными permissions.

Новый discovery не использует Telegram, VK, Дзен, YouTube, Livemaster или внешние страницы авторов. Основной охват дают публичный каталог и поиск Boosty, русские страницы Boosty в Common Crawl и site-restricted выдача `boosty.to`.
